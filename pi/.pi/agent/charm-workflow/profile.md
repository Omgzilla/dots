# Personal charm workflow profile

## Dwellir charm repositories

For Juju charm changes in Dwellir repositories, the coordinator and each role (builder, reviewer, tester) must load the installed `dwellir` and `dwellir-charm-development` skills. Follow the router and load additional Dwellir skills only when applicable. Use the change workflow and its role-appropriate references for planning, implementation, review, and testing. If the skills are missing, report that before claiming compliance.
